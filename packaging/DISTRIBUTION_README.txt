Hope Archive - Windows development preview
This portable layout is intended for local developer checks.
Ordinary users should download the complete Windows installer from:
https://github.com/BlackSeagull3104/HopeProject/releases/tag/v0.1.1-dev
Keep both EXEs together. Application protocol constants are included in the
Python backend. No user .env or development tools are required to run.
No personal credentials, sessions or archives are included.
The build is unsigned and requires Microsoft WebView2 Runtime.
