# 本地备份与隐私（Alpha.2）

Hope Archive 保存你自己的日记正文、富文本、媒体引用，以及记录中的评论正文、显示名和评论关联。不会按电话号码等文本模式修改你主动写下的内容。

新获取的 Hope 数据使用字段白名单：不保存无关的手机、QQ、邮箱、设备标识、登录 token、地址或额外用户资料。人员对象只保留账号 ID（归属/隔离/关联用途）及显示名。文本、日期、媒体、类型、天气、原有心情字段和必要评论关系保留；这不是新增情绪分析。

`backup/raw` 从此表示**最小化的源格式恢复数据**，不再表示逐字节 HTTP 抓包。分页数量、条目顺序、重复条目和已支持的归档字段保持；未知 API 字段不保存。源格式页面带有 `privacy_schema: 1`。无效/错误响应只保存无正文的状态标记，不保存服务端错误消息。原文不是匿名数据，备份仍应按私人文件保管。

`backup/normalized` 是归档与本地检索的数据来源；`backup/media`（位于各账号目录内）保存必要媒体。媒体地址是下载及重试所需的源引用，可能本身具有访问能力；不要公开 backup。`archive` 是日常阅读和整理的文档，便携图片资产仍按既有规则生成。AI 导出属于 `archive/AI回顾`，不是原始记录。

新策略不会自动清除、改写已有备份，也不承诺删除旧缓存/磁盘空闲区中的历史内容。旧版本 raw 可能包含额外人员资料，迁移仍按原策略保留原文件；请勿公开这些备份。需要历史数据清理时，应另行制定可恢复、明确授权的迁移方案。

FTS5 为本机关键词检索。Hybrid 是可选的本地关键词与语义组合，组件需显式下载并校验，不需要云端 embedding 或 AI 密钥。AI 生成仍需 BYOK，相关日记片段可能发送到用户选择的服务商，发送前有隐私说明。AI 保持实验状态；模拟 provider 合约测试不等于已验证真实服务商账户与联网生成。

界面提供可展开的简短说明。归档完成后可以打开归档文件夹；设置、OCR、胶囊、AI 导出也有相关目录入口。打开操作只接受固定输出类别，在后端从已选择的根目录解析，拒绝越界路径，不执行用户提供的 shell 字符串。
