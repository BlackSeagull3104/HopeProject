# 在线预览与导出体验

本轮为 main 源码功能，非新 Release。自动测试使用合成数据，不代表真实 Hope 响应或人工桌面验收已完成。

## 认证反馈

本地认证接口返回稳定的 `code` 和固定中文 `error`，React 现有可见错误区域展示 `error`。不回传原始服务器文案。没有已确认的失败数字状态码映射，不能由 HTTP 200 或任意非 1 状态猜测失败原因。

兼容规则仅匹配去掉首尾空白和末尾标点后的完整明确文案：

- 手机号未注册 / 该手机号未注册 / 该手机号尚未注册 / 该手机号尚未注册 Hope / 用户未注册 → `AUTH_PHONE_NOT_REGISTERED` → 该手机号尚未注册 Hope。
- 验证码登录中的 验证码错误 / 验证码不正确 / 验证码错误，请重新输入 → `AUTH_CODE_INVALID` → 验证码错误，请重新输入。
- 密码登录中的 密码错误 / 密码不正确 / 密码错误，请重新输入 → `AUTH_PASSWORD_INVALID` → 密码错误，请重新输入。
- HTTP 错误、连接失败或超时 → `AUTH_NETWORK_ERROR`，HTTP 503，提示网络或认证服务暂不可用；不自动重试短信。
- 其它文案、模糊“账号或密码错误”、无有效成功状态或响应格式异常 → `AUTH_UNKNOWN_ERROR`，固定通用提示。

上述文案是明确语义兼容规则，尚未通过真实失败响应验证。若服务端实际只返回不透明错误码，目前仍会显示通用提示。没有新增捕获或记录认证响应，没有修改协议常量，也没有读取个人 .env。

## 在线预览

React → Local Python API → 现有 Hope period diary API → 现有 normalized diary 模型 → React。

`POST /diaries/preview` 接受 `date` 及可选 `diaryType`；账号来自本地登录会话，不接受 userId。向 `services/v2/parallellife/period/dairy/list` 发送 beginDate=endDate=所选日期，复用分类映射和分页，最多50页，每页20条。与归档不同，`data_dir=None` 禁止原始响应及规范化文件写入；结果只在内存中使用。已知作者不匹配或日期不匹配将报错，不伪装为空结果。

保留正文、分类、心情、天气、留言及媒体元数据。媒体 URL 替换为会话内随机 key，前端不能提交任意 URL；`POST /diaries/preview/media` 按需获取 HTTPS 媒体，禁止重定向，检查解析地址为公网，仅允许图片/音视频 MIME，最大8MB，返回内存 data URI，不写文件。最多缓存400条引用，重新登录失效；大媒体请下载归档后打开。实际媒体/CDN兼容性待人工验证。

选日期自动加载；日期/分类切换不显示旧请求结果。加载、错误、空、成功分开；成功但没有日记才显示“木有日记哦~”。独立时间胶囊 V5 没有日期筛选参数，日期含义仍未确认，因此本轮不合并 Capsule 日期预览，页面明确引导至独立胶囊页。空状态只表示当天日记为空。

日期范围仍为 `start_date <= end_date <= today`；单日预览为 `selected_date <= today`。结束日期可选择，不锁死今天。

## 导出与目录

原生目录选择器继续使用 Tauri dialog；右侧 `...`，取消返回 null，不覆盖当前输入。浏览器模式保留手动输入。原生点击选择/取消仍待人工验收。

React 按范围导出将范围内条目合并成一个文件：`<昵称>的日记_<开始日期>--<结束日期>.<扩展名>`，支持 md/tex/pdf/docx。昵称来自登录会话，缺失或纯数字/手机号形式时使用 `Hope日记`；替换 Windows 禁用字符及控制字符，去掉末尾点/空格并限制昵称长度。不以内部用户ID命名。相同内容可跳过，不覆盖不同内容；零条记录不创建空文件。

归档下载中的单篇内部文件、旧无范围导出接口保留原有命名兼容性。Markdown 仍引用现有本地媒体，移动分享时须带上关联媒体；TeX 的图片写入输出目录的 assets。PDF/DOCX沿用现有渲染器。

Markdown 使用 `心情：哈　　天气：晴 ☀️` 同行布局。仅沿用已有 emotion_ha→哈、weather_qing→晴 的明确映射，晴添加 Unicode 太阳；不把“哈”擅自改成“开心”，不复制 APK 图片。未知 identity 原样显示，无 identity 的数字不猜测。
