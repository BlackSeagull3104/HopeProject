# 本地导出与界面工作流

本轮功能在 main 源码及本地构建中提供；GitHub 的 `v0.1.1-dev` 安装器未更新，不包含本轮导出改动。

## 格式

| 格式 | 实现与输出 |
|---|---|
| Markdown (.md) | 复用原导出器，保留原排版与相对媒体引用；媒体仍在归档目录 |
| TeX (.tex) | 每篇独立 ctexart 文档，XeLaTeX、Fandol 中文字体，图片复制为同级 assets 中的相对路径 |
| PDF (.pdf) | ReportLab 直接生成，无需 TeX；Windows 优先嵌入系统宋体，其他环境回退 STSong CID 字体 |
| Word (.docx) | python-docx 生成，可编辑；指定中文字体，图片嵌入文件，无本机绝对路径 |

四种格式共享 `YYYY/MM/日期_ID` 命名，默认保存至媒体归档目录，也可选择其他输出目录。相同内容重复导出跳过，不覆盖不同内容。无符合日期的日记时返回 0 篇，不伪造内容。

新格式按原文顺序输出文本、日期、情绪/天气和评论回复关系。只使用本地已下载的图片，不自动获取远程媒体。PDF/Word 嵌入图片；TeX 使用独立 assets。音频/视频显示说明，不嵌入可播放播放器。

横图、竖图保持比例并限制宽高；高度超过宽度 3 倍的长截图按顺序分段。原图不修改。Markdown 保留现有图片组排版。

## 使用

1. 登录后侧栏显示认证响应中已有的 `nickName`；缺失或空白时显示“Hope 用户”，不使用手机号或内部 ID 代替昵称。
2. 下载归档后，“导出”页自动填入标准化 JSON 和媒体目录；也可手动选择自己的旧归档路径。
3. 选择日期、格式和输出目录。目录字段右侧的 `...` 在 Tauri 中打开原生文件夹选择器；取消不改原值。浏览器开发模式提示手动填写。
4. 输出目录不存在时按现有导出约定创建；路径指向普通文件、无法创建或无写入权限时返回错误/失败数量，保留已有文件。
5. TeX 编译时在 `.tex` 所在目录运行 `xelatex -no-shell-escape 文件名.tex`，需安装 ctex、xeCJK、Fandol、geometry、graphicx 等 TeX 包。PDF 导出不需要安装这些包。

## 日期规则

**开始日期 ≤ 结束日期 ≤ 本机今天。** 结束日期独立可编辑，今天只是默认值和最大值；可以选择早于今天的日期，不允许未来日期或早于开始日期。

审计未发现此前 React 直接把结束日期写死为今天：原代码已有 `value={endDate}` 与 `onChange`，以及 `max=今天`。本轮明确保留可编辑状态，将日期控件用于下载与导出页，新增前端提交检查和共享后端校验。所有入口均保留未来日期限制，未实现旧 Prompt 中已被撤回的“允许未来日期”。

离线导出按标准化 `note_date` 的日期部分做包含两端的筛选；筛选时不包含缺失日期的条目。旧 `/export/markdown` 接口未传日期时仍导出全部条目；新 UI 始终传日期。

## 验证与手动检查

自动测试覆盖四种文件、内容/评论、图片宽高与长图分段、同内容跳过/不同内容拒绝覆盖、单日筛选、非法格式、日期边界以及两种登录的昵称。PDF 合成样本已进行页面渲染检查；Word 结构和图片范围已自动检查。TeX 合成样本已通过 XeLaTeX 实际编译，生成 7 页 PDF。

手动验收清单（不代表已经执行）：

- 登录，确认昵称或安全回退名称。
- 在“导出”选择四种格式，使用右侧 `...` 选择目录，再取消一次确认原值保留。
- 分别导出并打开文件，确认中文、评论、横/竖/多图和长截图可读。
- 结束日期选今天之前但不早于开始日期：应接受；选今天：应接受。
- 结束日期早于开始或晚于今天：应拒绝；修改结束日期后不应自动跳回今天。
- 在 Word 中检查 DOCX 实际分页；在安装了中文 TeX 包的环境编译 TeX。

本轮不重复真实账号认证，也不发布新 GitHub Release。测试使用合成日记，生成文件不提交 Git。复杂字体/emoji 支持取决于目标字体与阅读器，PDF 的非 Windows CID 回退仍需对应环境验收。
