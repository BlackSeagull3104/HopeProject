# 2026-09-09 上推变更记录

比较基线：962f963（上次 origin/main）。

## 新增功能

- auth.py：按用户提供并确认的三种 SHA1 规则生成短信 signature、验证码登录 sign、密码登录 signature。
- 复用一个 urllib transport，支持发送验证码、验证码登录和原始密码登录；明确 timeout，不自动重试或跟随重定向，不保存认证响应。
- 登录成功要求 status=1 与有效 datas.id；AuthResult 仅保留 user_id、mobile、nickname，默认 repr 隐藏这些字段。
- login_ui.py：短信/密码两种登录方式、掩码 secret 输入、后台请求、重复提交防护、短信成功后60秒倒计时、脱敏错误提示。
- ui.py：启动先登录，成功后显示归档窗口。删除手动 User ID 输入，使用 current_user.user_id 调用原 application.export_archive()；仅保留运行期间身份。
- 认证 CLI 支持 send-code、login、password-login；主归档 CLI 保持原有手动 ID 方式。
