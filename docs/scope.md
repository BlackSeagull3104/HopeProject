# Hope Archive 范围与验收

> 状态：V1 计划基线，尚未完成 M0 验证。更新日期：2026-09-06。当前仓库为初始化骨架，以下为交付目标，不代表已有能力。

本文是范围控制（Scope Control）的唯一版本清单。产品原则见 [project-concept.md](project-concept.md)，快速介绍见 [project-introduction.md](project-introduction.md)。长期愿景不自动成为本期承诺；范围改变时先更新本文并记录原因。

## 1. 项目目标（Project Goal）

完成一条可演示、可核对的单机归档链路：**本人授权数据或用户自有文件 → 原文、日期与图片关联的本地档案 → 浏览、日期筛选与中文关键词搜索 → 保真数据包与精美阅读版。**

先用不含隐私的合成样例验证流程（Sample-data-first），再在授权范围内核对实际数据。基础功能不依赖 AI、开发者云服务器或 Hope 接口持续在线。数据通道无法验证时，保留自有文件路线并向组员和老师说明定位调整。

## 2. V1 必做（Must Have）

| 项目 | 必做边界 |
| --- | --- |
| 一种明确的数据入口 | 本人授权且获允许的数据通道，或至少一种明确约定的用户自有文件格式；不要求两种都做。文档写明支持格式、来源和限制 |
| 原文与关联保全 | 保留正文、换行、表情、原始日期及可获取的时区、图片顺序与条目关联；缺失字段明确标注，不编造 |
| 本地保存 | 正文与已取得图片实际落盘；重启后可用；重复导入同一来源样本不新增重复记录；更新冲突不静默覆盖 |
| 浏览与日期筛选 | 简单本地界面提供列表、详情与起止日期筛选；同日多篇可区分，未知日期单独可见 |
| 中文基础关键词搜索 | 支持中文短词及基本中英混合内容查找；与日期条件组合；结果含日期、命中片段和原文入口，无结果时明确提示 |
| 保真导出 | 同时提供版本化 JSON 与 Markdown，并包含已保存媒体及清单；JSON 保留结构信息，Markdown 保留正文、日期和图片关联；同日多篇不覆盖 |
| 一种精美阅读格式 | 默认选择 HTML，提供年月导航、中文长文与按比例展示的图片；能离线打开。PDF 不与 HTML 同时列为必做 |
| 结果与失败可见 | 导入、导出提供成功、重复、失败及缺图计数或清单；失败可重试且不损坏已有档案，不要求复杂通用任务调度器 |
| 基础隐私与可用说明 | 基础路径无日记内容外发，凭据不进入日志或导出；说明启动、支持格式、保存位置、恢复方式与已知限制 |

“保真”相对于实际输入可取得的内容，不承诺恢复源端未提供或已删除的信息。远程图片地址不算已保存图片；无法取得时保留明确缺失记录，不宣称完整成功。未知总量不宣称全量归档。

## 3. 条件增强（Should Have）

**仅在 Must Have 稳定且时间允许，或正式课程要求需要时，从下列四项最多选择一个重点增强；允许一个都不选。当前未选定。** 若 rubric 要求 AI，优先在混合检索与月度摘要中选择，并重新估算工期。新增必做项必须明确替换或调整现有范围。

| 候选 | 选择条件 | 最小完成证据 |
| --- | --- | --- |
| PDF 阅读版 | 阅读质量是优先展示点，HTML 已稳定 | 中文、长文与多图样本无裁切或严重分页问题，内容与归档一致 |
| 混合检索（Hybrid Search） | 模糊查找需求明确，模型资源可接受 | 同一组人工标注查询比较基础与混合结果，记录命中和响应表现；结果可回原文 |
| 月度摘要（Monthly Summary） | 课程或用户需要 AI 回顾，隐私与成本路径明确 | 所选月份条目均被覆盖或报告失败，关键结论有原文入口，无编造事件，标注 AI 来源 |
| 真实增量同步（Incremental Sync） | 已验证真实入口、更新字段与允许的访问方式 | 用实际授权样本证明新增及旧文修改处理，不重复、不静默漏更；报告请求与媒体处理结果 |

重复导入去重属于 Must Have；它不能替代真实增量同步的证据。模型不可用时基础路径仍需工作。增强不达标可以退出本期，不用拖延完整基础版本。

## 4. V1 明确不做（Out of Scope for V1）

- 新日记编辑器、向 Hope 写回、社交发布和自动外部分享。
- 多平台连接器、多账号管理、多端云同步与开发者托管日记服务器。
- 把语义搜索、月度摘要、PDF 和真实增量同步同时承诺交付。
- 年度层级摘要、长期人格推断、情绪诊断或关系评分。
- 绕过权限、枚举他人内容、提前读取未开放胶囊或依赖疑似权限漏洞。
- 全质量媒体获取保证、所有历史数据恢复、通用任意文件解析。
- 跨平台安装包、自动更新、分发级签名和大规模公开服务。
- 完整静态加密与复杂密钥恢复体系；真实日记试用前仍需评估存储风险并说明实际保护能力。

若正式 rubric 要求其中某项，先修订范围与验收，不能静默加入。

## 8. 里程碑（Milestones M0–M4）

按退出条件推进，不在课程工期未知时承诺周数。

| 阶段 | 产物 | 退出条件 |
| --- | --- | --- |
| M0 可行性与范围冻结 | 合成样例、授权样本或自有文件样本、字段与入口说明、平台决定 | 确认至少一种可实现输入及完整性核对方式；Hope 通道未验证则明确文件路线与定位；更新本范围 |
| M1 归档核心 | 原文与日期及媒体关联、本地持久化、导入结果与去重 | 样本逐条一致，重启保留；重复导入不重复；失败重试不损坏已有数据 |
| M2 完整基础版本 | 浏览、日期筛选、中文搜索、JSON / Markdown 与 HTML | Must Have 全链路通过；导出包换目录后可离线使用，缺失可见 |
| M3 条件增强或稳定性整理 | 最多一个增强及评价结果，或基础体验修整 | 所选增强达到独立标准且无基础回归；无合适增强时直接完成稳定性整理 |
| M4 课程交付 | 可演示版本、运行说明、验证记录、已知限制及 rubric 对照 | 完成最小验收；正式要求已逐项核对，差距如实记录；公开演示不暴露私人数据 |

若正式 rubric 到 M4 仍未公布，只能报告软件基线完成，不能宣称课程验收已通过。

## 9. 完成定义与最小验收（Definition of Done）

以下是 V1 的完成门槛。用固定、不含隐私的样例集核对，覆盖无标题、中文短词、中英混合、表情、长文、多图、同日多篇、跨月、未知日期和缺失媒体；保留预期结果与实际结果。真实接入能力另用授权样本私下验证。

- [ ] **可导入与追踪**：说明支持的输入格式及范围；输入条数与成功、重复、失败结果可对账。未知源端总量明确标注。
- [ ] **内容完整**：逐条核对原文、原始日期与图片关联和顺序；不把导入时间冒充写作时间。每个预期媒体有本地文件或明确缺失原因。
- [ ] **持久且不重复**：关闭重开后内容一致；重复导入同一输入不增加重复条目。异常或中断后已有档案可读，失败部分可重试；不要求字节级断点续传。
- [ ] **基础任务可用**：按起止日期筛选结果正确、边界含义明确；中文短词及中英混合已知查询能找到预期记录，点击可回原文；未知日期与无结果状态清楚。
- [ ] **数据导出保真**：JSON 可解析，按条目核对与本地选定范围一致；Markdown 正文、日期和图片引用可用；文件名不冲突，清单报告格式版本与缺失。不以阅读版代替结构化导出。
- [ ] **HTML 可重读**：导出包复制到另一目录并断网后，年月导航、长文和已保存图片正常；中文可读、图片比例正确、无正文裁切。使用本地静态资源，不依赖外部字体或图片服务。
- [ ] **失败不误报**：至少验证一个无效输入、一次中断或写入失败、一个缺失媒体场景；已有档案不损坏，报告说明失败位置及重试方式，不把部分成功写成完整成功。
- [ ] **隐私边界成立**：基础路径断网可运行；检查运行网络行为及日志、导出，确认无默认日记外发或凭据泄漏；公开样例与演示不含真实私人记录。
- [ ] **使用说明可执行**：在目标系统按说明完成启动、导入、搜索与导出，不需配置 Agent 或模型；标明保存位置、支持限制与恢复方式。课程开发环境启动方式不等同于分发级安装体验。
- [ ] **承诺与证据一致**：每项必做有验证记录，所选增强单独验收；明确哪些只是文件导入、哪些经实际 Hope 数据验证；正式 rubric 到位后完成对照，不把尚未实现的设计写成成果。

仅创建这些文档不代表以上验收项完成。未满足的必做项应保持未勾选，或通过明确的范围变更重新确定承诺。
