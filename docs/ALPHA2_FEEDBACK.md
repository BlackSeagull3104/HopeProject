# Alpha.2 早期反馈处理记录

本记录对应早期测试旧版提出的七项建议；分类依据为 Alpha.1 源码和 Alpha.2 合成测试，不表示真实账号或全部在线服务商已人工验证。

| 关注点 | Alpha.1 状态与分类 | Alpha.2 处理及证据 | 保留限制 |
| --- | --- | --- | --- |
| Hope JSON 与评论者资料 | 确认：原始响应可能保存无关的人员元数据 | 新响应与合并备份采用字段白名单；人员仅保留关联所需 ID、显示名。合成标记测试检查备份、归一化、导出、检索、AI 上下文和错误日志 | 旧备份不会自动改写；媒体源地址仍可能带访问能力，备份应私密保管 |
| JSON 是内部材料 | 部分解决：已有 `backup` 和可阅读的 `archive` 区分 | 界面简短说明二者用途，并把归档文件夹入口放到相关操作附近；桌面版已验证打开目录 | 恢复和排错时仍可手动查看备份 |
| API 密钥状态与修改 | 部分解决：安全存储和配置状态已有，替换交互不够明确 | 已配置时需主动选择替换；删除需二次确认。前端只接收配置状态；合成 UI 和 provider 合约测试覆盖 | 未使用真实付费密钥逐一测试在线生成 |
| 语义检索 | 已解决：Alpha.1 已有 FTS5 与可选本地 Hybrid | 冻结后端实测 CPU Hybrid、索引、过滤、损坏回退；合成基准 R@5 为 FTS5 58.36%、Hybrid 91.60%，与 Alpha.1 一致 | 基准不代表真实用户准确率；组件需显式安装 |
| 文件位置引导 | 部分解决：已有选择目录，部分输出页缺少直接入口 | 设置、OCR、胶囊和 AI 导出加入受限的打开目录入口；后端仅接受固定类别并校验目录边界 | 尚未生成的目录不能打开 |
| 轻量入门说明 | 确认：术语较多 | 添加可展开说明，解释预览、归档、backup、archive、FTS5、Hybrid、OCR 与 AI；打包桌面版已显示 | 不替代完整帮助文档 |
| 归档后打开结果 | 确认：完成提示缺少直接操作 | 完成或部分成功时显示打开归档文件夹；合成归档与桌面打开操作已验证 | 不新增历史管理页面 |

Alpha.2 保留本地 RapidOCR、原有四种文档格式的渲染路径，以及 AI 的实验性 BYOK 提示。详细隐私边界见 [本地备份与隐私](PRIVACY_DATA.md)。
